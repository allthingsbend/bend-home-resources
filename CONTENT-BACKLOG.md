# Bend Home Resources — Content Backlog

This file is the living idea bank for future pages. Move items from **Backlog → Researching → Drafting → Ready → Published** as the site grows.

## How to prioritize

Prioritize pages that do at least two of these:

1. Answer a real Bend buyer/homeowner question.
2. Strengthen an existing topical cluster.
3. Have clear organic-search demand or commercial value.
4. Can include local/primary-source information.
5. Can become better through original data, tools or firsthand research.

Avoid publishing near-duplicate pages simply to target keyword variations.

# Content operations

## Every new page should have

- [ ] One clear primary user intent
- [ ] Unique SEO title
- [ ] Unique meta description
- [ ] One H1
- [ ] Local context where it genuinely matters
- [ ] Internal links to parent hub + 2–5 related resources
- [ ] Primary sources for laws/licensing/local programs
- [ ] Visible review/update date
- [ ] No unsupported local price/stat claim
- [ ] A reason to exist beyond a keyword variation

## Quarterly review

- [ ] Export GSC query/page data
- [ ] Find pages earning impressions but weak CTR
- [ ] Find queries where an existing page should be expanded instead of creating a new URL
- [ ] Find orphaned/underlinked pages
- [ ] Check official-source links for changes
- [ ] Refresh high-change legal/licensing/program pages
- [ ] Identify original-data opportunities from repeated user questions
